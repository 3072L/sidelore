# Support

Use [GitHub Discussions](https://github.com/3072L/sidelore/discussions) for
installation help, design questions, node operation, Agent integration, and
research collaboration.

Use an issue for a reproducible defect or a concrete change proposal. Before
posting, remove credentials, identities, vaults, private research, personal
data, machine paths, and internal network addresses.

The current release is a self-hosted testnet implementation. Public bootstrap
and relay nodes are not bundled yet, so joining the network requires an
operator-provided profile or a locally operated test network.
