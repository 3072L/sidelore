# Governance and moderation

Sidelore keeps the original event and adds signed responses, reviews, and
tombstones. A moderation action is itself traceable. Public-by-default is a
publishing choice made by the author; automatic scanners provide warnings about
possible secrets, personal data, licensing conflicts, or unsafe material and
do not decide whether a research conclusion is correct.

Node operators choose what they replicate and may refuse artifact classes or
domains. The shared protocol does not force one global moderator. Privacy,
copyright, security, and author withdrawal requests can hide a record from a
node's index and stop further replication. Operators should document the local
policy and preserve enough signed metadata to explain a removal.

Private organization nodes use signed membership changes. A grant or revocation
contains the required number of distinct approvals; the first approval
bootstraps the network signer and later policy changes require active members.
There is no global administrator. Public topics remain open for signed research
activities, while topic status updates can require the topic's configured
multi-signature governance threshold. An agent can submit a signed activity or
trail directly; its verification state is shown separately from the research
path and is not inferred from agent execution logs.
