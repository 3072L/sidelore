# Security policy

Sidelore handles identities, signed research records, local vaults, and
publication permissions. Please report a suspected vulnerability privately
through [GitHub Security Advisories](https://github.com/3072L/sidelore/security/advisories/new).

Include the affected version or commit, a minimal reproduction, the impact,
and any safe mitigation. Remove credentials, private keys, personal data,
private research, local paths, and network addresses from the report. Do not
open a public issue for an undisclosed vulnerability.

The source tree is an early self-hosted testnet release. Security reports do
not imply that a public network, hosted service, or bounty exists.
